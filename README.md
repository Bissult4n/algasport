# ALGA Sport Shop

Статический мобильный каталог на Next.js, React и Tailwind CSS. Production build создаёт `out/`: на хостинге не нужны Node.js-сервер, база данных, API или Google Sheets. Корзина хранится в браузере, заказ оформляется сообщением в WhatsApp.

Публичная тестовая версия: [ALGA Sport Shop staging](https://alga-sport-shops-2db1p7uia-bissultan-s-projects.vercel.app). Это preview, не коммерческий запуск: `noindex, nofollow`, WhatsApp отключён, текст заказа можно скопировать. Результат проверки: `docs/staging-deployment.md`.

## Запуск на Другом Ноутбуке

Установите Git и Node.js 24.x с npm (версия указана в `.nvmrc` и `package.json`). Замените `<REPO_URL>` настоящим адресом своего репозитория:

```sh
git clone <REPO_URL> alga-sport
cd alga-sport
npm install
npm run dev
```

Откройте [локальный сайт](http://localhost:3000/). Остановка: `Ctrl+C`. В PowerShell, если политика выполнения блокирует `npm.ps1`, используйте `npm.cmd` вместо `npm`. Если команда вообще не найдена, установите Node.js с npm и заново откройте терминал.

Все необходимые фотографии и SVG входят в репозиторий. Не нужны ручное скачивание ассетов, копирование файлов со старого ноутбука, скрытые локальные инструменты или env-файлы. Единственный lockfile: `package-lock.json`.

## Production Build и Проверки

```sh
npm ci
npm run lint
npm test
npm run build
npm run check:static
npm run check:repo
npm run preview
```

`npm ci` устанавливает точные версии из lockfile. `lint` проверяет TypeScript, это не отдельный ESLint. Готовая статика: [127.0.0.1:4173](http://127.0.0.1:4173/). `npm start` делает то же самое. Preview нужен только для локальной проверки, на Vercel он не запускается.

Дополнительные браузерные тесты после сборки:

```sh
npx playwright install chromium
npm run test:ui
npm audit
```

Тест сам запускает и останавливает preview на порту 4175; скриншоты попадают в игнорируемую папку `test-results/`. В Windows с Edge можно вместо скачивания Chromium задать `$env:PLAYWRIGHT_CHANNEL = "msedge"`. Ссылки WhatsApp/Instagram проверяются через перехват запросов: тест не отправляет сообщения и не подтверждает существование аккаунтов.

## Где Менять Данные

| Данные | Файл / настройка |
| --- | --- |
| WhatsApp | `lib/shop-config.ts`: `WHATSAPP_NUMBER` |
| Instagram | `lib/shop-config.ts`: `INSTAGRAM_USERNAME` |
| Доплаты за вышивку и backpatch | `lib/shop-config.ts`: `CUSTOMIZATION_PRICES` |
| Общие подсказки о наличии, доставка, оплата | `lib/shop-config.ts`: `SHOP_TERMS` |
| Цены, размеры, варианты, наличие модели | `lib/catalog.ts`: `price`, `sizes`, `variants`, необязательное `availability` |
| Точный корейский жгут | Существующая запись в `lib/catalog.ts`, фото в `public/images/equipment/` |
| Имена, фото, дан, описания владельцев | `lib/shop-content.ts`: `owners` |
| Реальные фотографии владельцев | Добавьте в `public/images/owners/`, путь `/images/owners/имя.webp` укажите в `photo` |
| Варианты и правила персонализации | `lib/customization.ts` |

Для публичного staging **номер WhatsApp оставлен пустым**. Личный тестовый номер удалён. Текст заказа и копирование доступны, реальный переход отключён. После подтверждения владельцами укажите постоянный номер: международные цифры без `+` и пробелов. Отправку покупатель подтверждает сам в WhatsApp.

Все цены и доплаты намеренно равны `null`: «Цена по запросу». Подтверждённые цены задаются числами в тенге. Если хотя бы одна цена неизвестна, итог не превращается в ноль. Наличие не резервируется автоматически. Доставка и оплата согласуются отдельно.

### Необязательные Env-переменные

Можно скопировать `.env.example` в `.env.local` и раскомментировать нужные настройки либо задать их в Vercel. `NEXT_PUBLIC_` означает, что значение будет видно посетителям: **не храните здесь секреты**.

- `NEXT_PUBLIC_WHATSAPP_NUMBER`: переопределяет номер; явно пустое значение отключает переход.
- `NEXT_PUBLIC_INSTAGRAM_USERNAME`: username без `@`.
- `NEXT_PUBLIC_SITE_URL`: адрес для метаданных; на Vercel по умолчанию используется домен текущего deployment.
- `NEXT_PUBLIC_BASE_PATH`: только для подпапки, например `/repository` на GitHub Pages. Для Vercel оставьте незаданным.
- `NEXT_PUBLIC_ALLOW_INDEXING=true`: разрешает индексацию после решения о запуске. По умолчанию staging помечен `noindex`. Это **не пароль и не ограничение доступа**.

После изменения настроек нужна новая сборка и публикация. Готовая статика не читает новые env-переменные при открытии страницы.

## GitHub и Перенос

Staging-состояние сохраняется локальным коммитом `Prepare ALGA Sport Shop staging deployment` на ветке `main`. Remote не задан: URL должен предоставить владелец. `npm run check:repo` проверяет кандидаты на добавление, изображения, lockfile, исключения и распространённые форматы секретов; он не заменяет просмотр файлов перед публикацией.

После создания своего пустого репозитория на GitHub:

```sh
git status --short
npm run check:repo
git remote add origin <REPO_URL>
git push -u origin main
```

Не повторяйте `remote add`, если remote уже существует; проверьте `git remote -v`. Для следующих собственных коммитов настройте свои `user.name` и `user.email`. Первый снимок использует явно технического автора Codex, без личного email владельца; глобальная конфигурация Git не меняется.

В Git входят исходники, конфигурация, `public/`, документация, тесты и npm lockfile. `.gitignore` исключает зависимости, сборки, кеш, env-файлы кроме `.env.example`, ключи, `.vercel`, результаты тестов и `design-assets/`. Последняя папка содержит только исходные референсы и архивные неиспользуемые изображения, для сайта она не нужна. Приватные скриншоты историй не входят в `public/` и не публикуются.

## Vercel: Тестовый Деплой

Используется существующий Vercel-проект `alga-sport-shops`; дубликат не создавался. Первый публичный preview опубликован напрямую через CLI, без GitHub. В дальнейшем подключите GitHub к этому же проекту. Root Directory: корень проекта. Существующий `vercel.json` задаёт:

| Поле | Значение |
| --- | --- |
| Framework Preset | Other (`framework: null`) |
| Node.js | 24.x |
| Install Command | `npm ci` |
| Build Command | `npm run build` |
| Output Directory | `out` |

Дополнительный конфиг, backend, серверные функции и SPA-rewrite не требуются. Товары и секции используют hash: `#product/zone-migaku`, `#catalog`, `#customize`. `.vercel` со старого ноутбука копировать не нужно. Не исключайте devDependencies при установке: они нужны для сборки.

Staging уже опубликован; текущий production-домен не переключался. При последующих preview deployments сохраняйте пустой `NEXT_PUBLIC_WHATSAPP_NUMBER` и `NEXT_PUBLIC_ALLOW_INDEXING=false`. GitHub push пока не выполнялся. До коммерческого использования также подтвердите право использования фотографий поставщиков.

### Другие Статические Хостинги

- Cloudflare Pages: `npm ci`, `npm run build`, результат `out`, без Workers.
- GitHub Pages: загружайте содержимое `out/` как Pages artifact, включая `.nojekyll`. Для адреса с именем репозитория задайте `NEXT_PUBLIC_BASE_PATH=/repository` до сборки.

Проверка подпапки в PowerShell:

```powershell
$env:NEXT_PUBLIC_BASE_PATH = "/repository"
npm run build
npm run check:static
npm run preview
```

Откройте `http://127.0.0.1:4173/repository/`. После проверки: `Remove-Item Env:NEXT_PUBLIC_BASE_PATH` и новая обычная сборка.

## Персонализация и Корзина

IJF backpatch: только фамилия и код страны, фиксированная спина и оформление. Вышивка: Unicode-текст, цвет, шрифт, ориентация и место на нижней части куртки или верхней части штанины. Фото с отмеченными зонами использовано только как ориентир размещения, не масштаба или сертификации. SVG наложен на настоящие фото Adidas Champion II как подписанный пример, не фото каждой модели. Финальный макет и требования соревнований согласуются перед изготовлением.

Корзина хранится в `localStorage` под ключом `alga:cart:v2`; доступны количество, редактирование, удаление и общий текст заказа. Старые записи мигрируют с проверкой данных. Если хранилище запрещено, корзина работает до закрытия страницы с предупреждением. После WhatsApp корзина не очищается: открытие мессенджера не означает отправку или подтверждение заказа. Централизованного учёта клиентов нет.

## До Запуска Магазина

- Подтвердить постоянный WhatsApp (в staging номер пустой, переход отключён).
- Указать цены, отдельно стоимость вышивки и backpatch.
- Получить имена и настоящие фото обоих владельцев; дан и описание по желанию.
- Подтвердить размеры, варианты и фактическое наличие.
- Согласовать доставку и оплату.
- Уточнить марку, модель и фото корейского жгута.

Источники 23 локальных фотографий: `docs/image-sources.json`. Предыдущая визуальная доработка: `docs/project-report.md`. Техническая проверка: `docs/deployment-readiness.md`.
