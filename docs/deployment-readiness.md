# ALGA Sport Shop: Проверка Готовности к Staging

Этот отчёт описывает проверку до публикации. Последующий публичный preview и его проверки зафиксированы в `staging-deployment.md`.

Дата проверки: 9 сентября 2026 года. Проверено на Windows, Node.js 24.19.0, npm 10.9.4 и Edge/Chromium через Playwright. Дизайн, 12 товаров, категории и архитектура без backend сохранены.

## Результат

**Технически готов к тестовому публичному размещению.** Production build проходит, результат полностью статический. Реальный GitHub push и Vercel deployment в рамках этой проверки не выполнялись. Это не окончательный коммерческий запуск.

Чистая копия собрана только из файлов, предназначенных для Git, без `.local-tools`, старых `node_modules`, кеша сборки, env-файлов, `.vercel` или архива изображений. Зависимости установлены заново. Затем в изолированной копии проверен отдельный env-профиль с подпапкой и отключённым WhatsApp; он не перенесён в рабочий проект.

Временные копии проверки оставлены в системной папке Temp: автоматическую очистку заблокировала среда выполнения. Они находятся вне репозитория и не участвуют в публикации. Тестовые серверы остановлены.

На текущем ноутбуке доступный Node.js не имеет npm в PATH. Для проверки использовался стандартный npm 10.9.4 из локального кеша инструментов. В коде и lockfile нет зависимости от этого расположения. На другом ноутбуке достаточно обычной установки Node.js с npm, как описано в README.

## Исправления

- Добавлен единый переносимый `package-lock.json`, версии прямых зависимостей зафиксированы. Удалены прежний pnpm lockfile и некорректный workspace-конфиг. Локальная запись, возникшая при промежуточной тестовой установке, устранена полной регенерацией lockfile в новой папке.
- Обновлены уязвимые зависимости без `npm audit fix --force`, подавления предупреждений или смены архитектуры. Next.js: 16.2.6 → 16.3.4; PostCSS: 8.5.15 → 8.5.28; sharp: 0.34.5 → 0.35.4. `@next/env` согласован с Next.js. React и Tailwind не переводились на новую основную версию.
- Первоначальный аудит сообщал о трёх уязвимых пакетах: одной critical и двух high. Конечный аудит не сообщает об уязвимостях. Это проверка известных advisory, не гарантия отсутствия любых ошибок.
- Playwright, sharp и загрузчик env объявлены явными зависимостями инструментов. Скриптам не нужны абсолютные пути к библиотекам на старом ноутбуке.
- Исправлены закрытие модального окна при переходе на секцию, якорь `#customize`, синхронизация после очистки хранилища другой вкладкой и добавление существующей позиции при лимите 50 позиций. Превышение 99 единиц теперь объясняется сообщением, а не молчаливым обрезанием.
- Обновлён локальный preview: согласованные env/base path, корректная обработка чтения файлов, HEAD и отсутствие кеширования для QA.
- Контакты, доплаты, доставка и оплата находятся в `lib/shop-config.ts`; цены и наличие моделей в `lib/catalog.ts`; владельцы в `lib/shop-content.ts`. Поддержаны необязательные публичные env-переопределения.
- Добавлены `.env.example`, `.nvmrc`, `.gitattributes`, расширены `.gitignore` и `.vercelignore`. Отключено создание дополнительных служебных Markdown-файлов самим Next.js при `dev`-запуске (`agentRules: false`).
- Два неиспользуемых скриншота историй с персональными данными перенесены из `public/` в локальный игнорируемый архив `design-assets/unused-story-images/`. Рабочие фотографии товаров и логотип сохранены.
- Существующая статическая конфигурация Vercel приведена к npm. README содержит установку, запуск, проверки, настройки, перенос и публикацию.

Официальные сведения о затронутых зависимостях: [Next.js advisory](https://github.com/vercel/next.js/security/advisories/GHSA-p293-qw3h-jr36), [PostCSS advisory](https://github.com/advisories/GHSA-fxqj-rqcc-2cmp), [sharp advisory](https://github.com/advisories/GHSA-rgj7-g3m4-5g8c). Статический export не разворачивает Next.js-сервер; обновления также защищают локальную разработку и инструменты сборки.

### Неблокирующая Пометка npm

В npm 10.9.4 на Windows команда `npm ls --depth=0` отмечает `@img/sharp-wasm32` и `@emnapi/runtime` как `extraneous`. Это воспроизводится после чистого `npm ci`; штатный `npm prune` в изолированной копии пометку не устраняет. Они относятся к optional-ветке sharp для других окружений. Нативный sharp на Windows отдельно проверен чтением метаданных локальной фотографии, production build и все UI-тесты проходят, `npm audit` возвращает 0. В браузерном коде эти пакеты не используются.

Эта диагностическая пометка оставлена явно задокументированной: ради её скрытия не добавлены ненужные прямые зависимости, не удалены платформенные записи из lockfile и не отключены optional-зависимости. `node_modules` в Git и статический export не входит. Сообщение `npm fund` также информационное, не ошибка сборки.

- Общий текст заказа, неизвестные цены, копирование в буфер, правильное URL-кодирование и открытие новых вкладок WhatsApp/Instagram.

В основных проверенных сценариях не обнаружены ошибки JavaScript/консоли, отсутствующие assets или внешняя зависимость загрузки витрины. Физический iPhone, Safari и настоящий Linux/Vercel build не использовались; проверен статический экспорт и конфигурация размещения.

## GitHub и Vercel

Git инициализирован на `main`. История не переписывалась, коммитов и remote пока нет. Кандидаты на добавление проверены: исходники, SVG, конфигурация, документация, lockfile и все фотографии доступны для Git. Кеш, сборки, локальные env, ключи, `.vercel`, результаты тестов и частный архив исключены. Сканер не обнаружил распространённых форматов секретов или локальных runtime-адресов; перед публикацией всё равно нужен обычный просмотр diff. Права коммерческого использования фотографий поставщиков следует подтвердить у правообладателей.

**Можно готовить первый commit/push исходников.** URL GitHub-репозитория должен предоставить владелец; он не придуман и remote не добавлен. Команды переноса и первого push приведены в README.

Параметры Vercel уже записаны в `vercel.json`:

- Framework Preset: **Other** (`framework: null`).
- Root Directory: корень репозитория.
- Install Command: `npm ci`.
- Build Command: `npm run build`.
- Output Directory: `out`.
- Node.js: рекомендуется 24.x.
- Дополнительный backend, adapter, rewrite или сервер не нужны.

Основание: [Next.js static export](https://nextjs.org/docs/app/guides/static-exports), [Vercel project configuration](https://vercel.com/docs/project-configuration), [npm ci](https://docs.npmjs.com/cli/v11/commands/npm-ci/). По умолчанию staging закрыт от индексации метатегом, но доступен любому обладателю ссылки: `noindex` не заменяет авторизацию.
