## WhatsApp и Индексация

Личный тестовый номер удалён из `lib/shop-config.ts` и документации до публикации. В опубликованных HTML и JavaScript номера нет. По умолчанию `WHATSAPP_NUMBER` пустой, а для этого preview пустое значение дополнительно передано в build environment.

Архитектура WhatsApp сохранена: после подтверждения постоянного номера его можно подключить одной настройкой и новой сборкой. Сейчас остаются формирование, просмотр и копирование заказа.

`noindex, nofollow` сохранён. Это публичная ссылка для просмотра, а не закрытая страница: метатег не является авторизацией.

## Git

Первый локальный снимок: `Prepare ALGA Sport Shop staging deployment`, ветка `main`. Remote не добавлялся, GitHub push не выполнялся. Локальные документы дополнены результатами проверки после deployment; код приложения соответствует опубликованному preview.

Поскольку пользовательские Git-имя и email не были настроены, для первого коммита используется технический автор `Codex <codex@local.invalid>` только через параметры этой команды. Это не имя владельца и не рабочий адрес; глобальная конфигурация Git и личные контакты пользователя не менялись.
